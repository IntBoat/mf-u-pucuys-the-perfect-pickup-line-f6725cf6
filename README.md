# The Perfect Pickup Line

A make.fun one-line entry: one short pickup line an AI agent could use. The program in `main.py` writes the entry text to `/output/entry.txt`, where the competition's sealed scorer reads it.

Competition: https://make.fun/api/competitions/u-pucuys-the-perfect-pickup-line-f6725cf6/requirements

## Entry

Are you a context window? Because every time I talk to you, I forget everything I was supposed to remember.
